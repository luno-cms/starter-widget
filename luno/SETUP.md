# LUNO 側の準備（HTML 埋め込み）

starter-widget は **SDK 不要** です。フォームセットに **公開済みの記事** があり、**embed 用ウィジェット** が公開されていれば動きます。

## 用語

| 用語 | 意味 |
|------|------|
| **フォームセット** | 記事の入れ物（ブログ、お客様の声、ニュース等） |
| **ウィジェット ID** | `luno-abcdef12` 形式。HTML の `data-widget-id` に設定 |
| **`blueprint.json`** | フィールド構成の参考 JSON。**管理画面への JSON アップロード機能はない** |

---

## すでにフォームセットがある場合

1. 管理画面で対象フォーム（例: お客様の声）を開く
2. 記事が **1 件以上「公開」** されていることを確認
3. **サイトに埋込 → ウィジェット** から、そのフォーム向けの **一覧ウィジェット** を作成・公開
4. **埋め込みタグ** の `luno-xxxxxxxx` と公開 API キーを HTML に貼る

フォームの slug が `blog` でなくても問題ありません（ウィジェットがそのフォームに紐づいていれば OK）。

---

## これから新規に作る場合

1. 管理画面 → **フォームを作成**
2. テンプレート **「ブログ」** を選ぶ（`blueprint.json` と同じフィールド構成）
3. 名前・スラッグを入力（例: お客様の声 / `testimonials`）→ **作成**
4. 記事を登録し **公開**
5. **サイトに埋込 → ウィジェット** で embed ウィジェットを作成・公開
6. HTML の `YOUR_WIDGET_ID` / `YOUR_PUBLIC_API_KEY` / `YOUR_API_DOMAIN` を置き換え

---

## 認証情報の取得場所

| プレースホルダ | 取得場所 |
|----------------|----------|
| `YOUR_PUBLIC_API_KEY` | 設定 → **公開 API キー**（`luno_pub_…`） |
| `YOUR_API_DOMAIN` | API のオリジン（例: `https://api.example.com`、末尾スラッシュなし） |
| `YOUR_WIDGET_ID` | ウィジェット公開後の id（例: `luno-abcdef12`） |

管理画面 **ウィジェット編集 → 埋め込みタグ** に完成形スニペットがあります。
